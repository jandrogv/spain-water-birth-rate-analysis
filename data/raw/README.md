# Raw data

This directory contains the original public source extracts used by the data-preparation workflow in `scripts/01_prepare_datasets.Rmd`.

The source tables are attributed in the original thesis to the Spanish National Statistics Institute (INE), except territorial-area data, which are attributed to the Ministry for Ecological Transition and Demographic Challenge. Consult the thesis and `docs/power-bi-source-update.md` before redistributing or replacing any source extract.

## Reproducibility note

The preparation script expects `Poblacion_Comunidad.xls` in this directory, but that input is not present in the committed repository. Stage 1 cannot be rendered until the owner supplies or formally resolves that dependency. No substitute has been inferred or created.
