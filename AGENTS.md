# AGENTS.md — Data Analysis Portfolio Repository

## Project context

This repository contains a Bachelor's thesis project focused on the analysis
of water levels up to 2022 and birth rates in Spain.

The project includes:

- Data acquisition and preparation.
- ETL and data transformation processes implemented in R.
- Exploratory and statistical analysis.
- Data visualisations created in R.
- A Power BI dashboard for interactive analysis.
- The original Bachelor's thesis.
- Dashboard screenshots stored under `Cuadro de Mandos/Images`.
- Existing project documentation and an initial bilingual README.

## Portfolio objective

Prepare this existing repository as a professional, recruiter-facing data
analytics portfolio project.

The repository should demonstrate:

- Data analysis.
- Data cleaning and transformation.
- ETL workflow design.
- R programming.
- Statistical and exploratory analysis.
- Data visualisation.
- Power BI dashboard development.
- Communication of analytical findings.
- Clear and professional technical documentation.

## Language policy

- All final public documentation must be written in English.
- The final README must contain only the English version.
- The original Bachelor's thesis may remain in Spanish.
- Existing Spanish source-code identifiers and dataset fields must not be
  renamed unless explicitly requested.
- Spanish data fields may remain unchanged when explained through English
  documentation.
- Dashboard screenshots and public-facing image captions should be presented
  in English whenever possible.

## Accuracy requirements

- Do not invent data sources, metrics, conclusions or technologies.
- Every important statement must be traceable to an existing file, script,
  chart, dashboard page or thesis section.
- Clearly distinguish verified project results from recommendations for
  improving their presentation.
- Preserve limitations and contradictory results when they exist.
- Do not exaggerate causal relationships between water levels and birth rates
  unless the original analysis supports such a conclusion.
- Describe correlations, associations and trends accurately.

## Power BI dashboard

The folder `Cuadro de Mandos/Images` contains screenshots of the existing
Power BI dashboard.

These screenshots should be reviewed as potential portfolio assets because
they allow visitors to understand the dashboard without downloading or opening
the `.pbix` file.

For each screenshot, determine:

- Which dashboard page it represents.
- What analytical question it answers.
- Which indicators or visualisations it contains.
- Whether it is readable at GitHub width.
- Whether it contains private or unnecessary information.
- Where it should appear in the README or detailed documentation.
- Whether the filename should later be translated or standardised.

Do not edit, crop, rename or remove screenshots during the initial audit.

## Repository workflow

## Public repository principles

The final repository should:

- Be understandable without opening the R scripts.
- Show the project problem, methodology and results in approximately two
  minutes through the README.
- Use dashboard screenshots to demonstrate the Power BI result.
- Provide links to detailed English documentation.
- Explain where the data came from.
- Make clear which files contain the ETL, analysis, visualisations and
  dashboard.
- Preserve the original academic work while improving its presentation.
